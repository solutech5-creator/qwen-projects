# qwen-projects

مجموعة مشاريع وأمثلة تطويرية خفيفة، تشمل واجهات HTML/CSS/JS وأدوات تجربة واجهات الذكاء الاصطناعي.

## الأمثلة المتاحة

|المثال|الوصف|التشغيل|
|---|---|---|
|[Gemini API — توليد نص عربي](examples/gemini-api/)|مثال Python وREST لاستخدام واجهة Gemini الحديثة مع تعليمات عربية وإعدادات توليد قابلة للضبط.|راجع [دليل المثال](examples/gemini-api/README.md).|

## ملاحظة أمنية

لا تضع مفاتيح API أو ملفات البيئة المحلية في المستودع. يعتمد مثال Gemini على متغير البيئة `GEMINI_API_KEY`، وقد أُعد ملف `.gitignore` لاستبعاد ملفات البيئة والاعتمادات المحلية.
